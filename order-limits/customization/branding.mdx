The **Branding** page controls how limit messages look on your storefront.
Changes apply to all limits and include a live preview so you can see the
result before saving.

## Preset

Start from one of three presets:

- **Light theme**
- **Dark theme**
- **Basic theme**

## Position

Choose the **Display type**:

- **Inline** — the message renders directly on the page, near the product
  form or cart items
- **Popup** — the message appears as a popup

## Styling

Fine-tune the appearance:

| Setting | Description |
| --- | --- |
| Background color | Message background |
| Text color | Message text |
| Font family | Typeface used for messages |
| Text alignment | Left, Center, or Right |
| Font size | Message text size |
| Contact us button color | Color of the contact button, when shown |

## Advanced settings: custom CSS

The **Custom Css (Developer Zone)** field accepts your own CSS for full
control over the message appearance — useful when your theme needs
something the styling controls don't cover.

<Warning>
  Custom CSS is applied as-is. Test on your storefront after saving, and
  clear the field to return to the standard styling.
</Warning>

## Preview and save

Use the **Preview** panel to check the result, then click **Save**.
**Reset** restores the default branding.
