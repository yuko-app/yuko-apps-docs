Shopjar connects to two automation platforms, both configured under
**Settings → Integrations** and both requiring the **Growth** plan.

<CardGroup cols={2}>
  <Card title="Klaviyo" icon="envelope-open-text" href="/shopjar/integrations/klaviyo">

  <Card title="Shopify Flow" icon="diagram-project" href="/shopjar/integrations/shopify-flow">

Both integrations emit the **same twelve program events** — one for
each moment in the referral and affiliate lifecycle — so anything you
can email through Klaviyo, you can also automate through Flow.

| Event moment | Program |
| --- | --- |
| A member joins the referral program (welcome) | Referral |
| A referrer invites a friend | Referral |
| A friend claims their reward | Referral |
| A referrer earns a reward | Referral |
| A referral sale is made (admin) | Referral |
| An affiliate application is received (admin) | Affiliate |
| An application is approved | Affiliate |
| An application is rejected | Affiliate |
| An affiliate earns a commission | Affiliate |
| A payout is processed | Affiliate |
| A commission is redeemed as a coupon | Affiliate |
| An affiliate sale is made (admin) | Affiliate |
