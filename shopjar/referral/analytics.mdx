**Referral → Sales & Analytics** shows the program's performance:
metric cards for **Revenue**, **Referrer Rewards**, **Friend Rewards**,
and **Members**, a referral revenue chart, and a time filter (Today,
Yesterday, Last Week, Last Month, Last 3 Months, All Time).

## Reports

| Report | What it shows |
| --- | --- |
| Sales | Every referral-attributed order — date, referrer, customer, order ID, amount, coupon, and the reward rule that fired |
| Referrer Rewards | Each referrer reward with status (Approved / Pending / Cancelled / Claimed / Fraud) — approve, cancel, or mark fraud in bulk here when using manual approval |
| Friend Rewards | Coupons issued to referred friends |
| Referral Invites | Invite history with status (Invited → Successful) |
| Discounts | Every referral coupon with its status (Active / Claimed / Cancelled) and expiry |

Every report has an **Export** button that downloads a CSV — useful for
finance reconciliation or deeper analysis in a spreadsheet.

<Tip>
  The ratio to watch: **Friend Rewards claimed vs Sales completed**.
  Many claims but few sales means friends grab the coupon but don't
  buy — try a stronger friend offer or a lower minimum purchase.
</Tip>
