## Translating the drawer

Every text field a shopper can see — headers, bar messages, button
labels, badges — has a translation bar above it. Shoppers see the
language matching your storefront's locale; everything else falls back
to your default language.

Supported languages: English, French, Spanish, Portuguese, German,
Italian, Russian, Hungarian, Chinese, Japanese, and Korean.

How it works, per field group:

<Steps>
  <Step title="Add a language">
    Click **Add language** on any text field's translation bar and pick
    the language. Related fields share one language set — for example
    the progress bar's three messages are translated together.
  </Step>
  <Step title="Fill in the translated text">
    Switch to the language tab and type the translation. Shortcodes
    (like the cart total) work the same in every language.
  </Step>
  <Step title="Manage languages">
    Use **Make this language default**, the per-language enable toggle,
    or **Remove** from the **More actions** menu on each tab.
  </Step>
</Steps>

<Tip>
  Empty translated fields fall back to your default language — so you
  can translate the high-visibility texts first (progress bar, checkout
  button) and finish the rest later.
</Tip>

## The admin in your language

The app's own dashboard has a separate language switcher — it changes
what *you* see while working, and never affects your storefront.

## Shopify Markets support

Two per-market features help international stores:

- **Reward thresholds per market** — the
  [rewards bar](/cart-drawer/cart/rewards-bar#different-thresholds-per-country)
  can require different amounts per Shopify Market (e.g. $50 vs €45).
- **Market preview** — the cart editor's **Previewing market** selector
  renders the drawer exactly as that market's shoppers see it, currency
  included.
