**Order notes** adds a simple text box to the cart footer where shoppers
can leave special instructions — delivery notes, engraving text, gift
messages. Find it under **Footer → Order notes**.

## Settings

- **Title** — the label above the box
- **Placeholder** — the hint text inside it
- **Styles** — input and section colors

Notes arrive on the Shopify order as the standard order note, so they
show up wherever you process orders.

<Tip>
  A specific placeholder gets better notes. "Gift message or delivery
  instructions…" prompts useful text; a blank box collects "hello".
</Tip>
