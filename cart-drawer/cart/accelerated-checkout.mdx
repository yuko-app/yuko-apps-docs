**Accelerated checkout buttons** show express options (Shop Pay, PayPal,
and similar) near the checkout button, letting shoppers skip straight to
their saved payment method. Find it under **Footer → Accelerated
checkout buttons**.

## Settings

| Setting | What it does |
| --- | --- |
| Button size (desktop) / Button size (mobile) | Size the buttons separately per device |
| Make buttons collapsible | Tucks the express buttons behind an expandable accordion with a title |
| Is collapsed by default | Starts the accordion closed |
| Title color | The accordion title's color |

<Tip>
  If your footer is getting tall, make the express buttons collapsible
  and collapsed by default. Shoppers who want Shop Pay will open it;
  everyone else gets a cleaner path to the main checkout button.
</Tip>
